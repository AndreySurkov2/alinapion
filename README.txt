Как выложить на GitHub Pages:
1. Создайте репозиторий и загрузите ВСЁ содержимое этой папки в корень (index.html, styles.css, script.js, папка images, файл .nojekyll).
2. Settings -> Pages -> Source: Deploy from a branch -> Branch: main, папка / (root) -> Save.
3. Через 1-2 минуты сайт откроется по адресу https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/
Главная страница обязательно должна называться index.html (не main.html).
